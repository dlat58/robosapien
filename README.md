This repository contains micropython classes to control Robosapien V1 and V2
simply swap the commands file to rs_commands or rsv2_commands
this was mostly generated by AI
but note if you try this yourself, AI did not modulate the carrier, so you might need to do that
this uses PWM to modulate the carrier and turn it on or off for the required periods
I have seen implementations they attempt to do this using just timing control, but that did not work for me
is all very basic and can definitely be improved

see main.py for basic usage
note that you will need to add some sort of delay between commands (you will need to work out hom much)
